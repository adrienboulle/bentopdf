Destinations

Send the result of a tool to your own HTTP endpoint instead of, or in addition to, downloading it. Files are still processed in your browser; only the finished result is uploaded.

Credentials are stored in this browser. Header values, including API tokens and Basic authorization headers, are saved unencrypted in this browser's local storage. Anyone with access to this browser profile can read them. Use a token scoped to uploads only, and clear the destination on a shared computer.
